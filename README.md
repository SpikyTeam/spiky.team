# spiky.team

The team landing page published at [spiky.team](https://spiky.team).

It is built and deployed by GitHub Pages: `pages.yml` takes `spiky/` from
[SpikyMC-Sites](../SpikyMC-Sites), where the page is edited, and uploads it.
GitHub Pages does the building here, so this repository has no workflow of
its own and no page sources.
